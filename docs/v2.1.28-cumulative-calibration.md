# 秒选 2.1.28：选片偏好累计学习

- 从本版开始，每次导入完整的人工最终留片，都会将该任务的留片/未留片标签及本机视觉特征存入用户目录的 SQLite 历史库。不保存原图像素或明文路径，不修改原片或星级。
- 按拍摄题材分别累计。相同 JSON 任务 ID 再导入会替换该任务的旧反馈；同题材重复的原片路径只计一次。CSV 历史日志没有任务 ID，以原片完整路径集合识别同一任务。
- 每次用该题材已积累的全部样本重新训练，并按连拍组隔离留出验证。验证不足时只暂存反馈，仍使用上一次通过验证的偏好；下一次补导会再一起尝试。没有固定的任务条数上限，但磁盘空间、训练时间与内存消耗会随样本增长，不能保证无限物理容量或准确率单调提升。
- 2.1.27 及以前仅保存一份模型权重，没有逐张样本；旧任务须通过「用以前的任务学习」补导后才能进入累计历史。旧偏好在对应题材尚无通过验证的新偏好时继续作为回退。
- 累计反馈只用于 1 星原片保留偏好，不把最终交付原片自动当成 3 星精修标签，也不跨题材混训。当前任务的星级不会被学习动作直接重写。
