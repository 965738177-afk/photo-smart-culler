# 秒选 2.1.27 轻量版交付记录

Mac 与 Windows 的标准 PyInstaller 配置不再下载或收集约 3.3 GB 的 Qwen GGUF 内容模型及 llama.cpp 运行时。桌面设置移除了相应开关，分析入口固定使用已有快速路径；婚礼规则库、小型视觉模型、预览、星级及导出逻辑保留。开发用的模型推理源码与测试仍在仓库，便于未来有独立质量证据时重新评估，但标准安装包不包含其权重。

此取舍不等于准确率提升。2.1.26 默认已经关闭大模型，尚无独立跨婚礼验证证明启用它能稳定提高选片质量；安装包变小也不代表每批分析一定更快。

Apple Silicon Mac 包位于本地 `release/v2.1.27/`，未纳入 Git（安装包约 230 MB，超过常规 GitHub 单文件限制）。最终 ZIP 为 230,106,286 字节，SHA-256 `ba8e3068371f079d8c1be333840dd2f3b1cba1ced7b4ea7af6818291d46711b3`。原 2.1.26 ZIP 为 3,347,060,332 字节。

验证：`mvp_tests` 和 `tests` 合计 1774 项通过，1 项 Windows 原生 ExifTool 测试在 Mac 跳过；新 Mac 安装包的签名、ZIP CRC、包内无 GGUF/llama 文件检查，以及包内启动的按钮/设置/触摸板/JPG 星级写入回读/2764 张虚拟网格 smoke 测试均通过。Windows 打包配置已同步调整，尚未在 Windows 原生环境构建和验收。
