## 决策顺序、动作和能力标记

执行顺序：照片类型/用途 → 主体可用性 → 该类型的表情与动作门槛 → 时机和人物关系 → 同组比较 → 整场故事覆盖 → 客户风格偏好。

| 动作 | 含义 |
| --- | --- |
| 门槛 | 有充分证据才限制自动 3 星；不等于删除原片 |
| 择优 | 同用途且门槛通过后，决定哪张更优；不直接保证 3 星 |
| 覆盖 | 为一个事件、人物或用途保留可用代表；星级仍由质量决定 |
| 复核 | 有内容价值但证据不足，优先留下代表让用户确认 |
| 控制 | 星级、分组、去重、冲突处理或版本管理 |

| 能力 | 后续实现需要什么证据 |
| --- | --- |
| R | 规则和任务状态即可执行 |
| T | 解码、主体清晰度、曝光等技术检测 |
| F | 逐脸可见性、眼部、表情和头部方向 |
| V | 内容、动作、物体关系和场景识别 |
| S | 相邻帧、参与者组合及事件比较 |
| U | 用户确认、交付约定或认可样片 |

能力标签不是现有完成状态。多标签表示需要联合证据，缺项时不得假装确定。主要人物与家庭身份以用户确认结果为准；禁止凭年龄、衣服或位置断言亲属关系。

v2.1.23 起统一星级：1 星＝保留原片；3 星＝保留池内的精修候选；2 星＝摄影师人工确认，自动筛选和偏好校准不生成 2 星；无星＝本次未入选，不执行删除。交付原片包含所有有星照片（1/2/3），3 星不增加交付总数。证据不足仍须说明疑点，不能将所有未知照片塞入 1 星；1 星不是已由摄影师验收的保证，3 星也不是完美成片的承诺。

冲突时：用户明确手动决定优先；内容类型的合理豁免优先于通用姿态规则；主体质量门槛约束自动精选；关键事件覆盖可保留疑问代表但不能强行升 3 星；风格与张数要求不能覆盖上述判断。角色、眼部或事件证据不充分时，保留未知状态。

## 01．星级、用途与证据（W001—W010）

W001 【R｜控制】目标张数只指导交付规模；合格候选不足时报告差额，不用明显失误补足 3 星。

W002 【R｜控制】3 星数量可以为零，不按固定比例强制产出精选。

W003 【R/U｜控制】用户手动设定的星级保持优先，重新分析和偏好校准不得悄悄覆盖。

W004 【V/U｜控制】正式留念、纪实瞬间、艺术肖像分别判断；分类不明时不套用单一审美门槛。

W005 【R/S｜复核】证据不足只保留有内容价值的疑问代表，不给整批未知照片统一 1 星。

W006 【R｜控制】未入选与删除分开；所有规则只决定建议星级，不直接删除源文件。

W007 【R/U｜控制】交付全片、精简相册与社交精选是不同用途，选片数量与去重范围分别设置。

W008 【R｜控制】推荐原因显示实际观察和疑点；无法确认时使用“疑似/无法判断”，不输出肯定身份或情绪结论。

W009 【R/U｜控制】客户确认的必留人物和环节参与覆盖检查；缺照片时提示缺项，不虚构识别结果。

W010 【R/U｜控制】用户否定的代表片按具体原因入回归样例；不得将一次偏好扩大为所有婚礼的绝对规则。

## 02．主体清晰度与技术可用性（W011—W020）

W011 【T/V｜门槛】背景很清晰但关键人物明显虚焦时，不以整图清晰度给 3 星；先定位主体。

W012 【T/F｜择优】合影中比较关键人物和各排脸的清晰度，不仅比较最近或最大的一张脸。

W013 【T/U｜复核】轻微噪点按预计输出尺寸判断；弱光照片不因高 ISO 自动淘汰。

W014 【T/V｜门槛】关键人物面部或关键细节严重过曝不可用时限制精选；背景窗口亮不单独判废。

W015 【T/V｜复核】暗调照片先判断主体能否辨认和后期可用性，不因画面平均亮度低直接淘汰。

W016 【T/V｜择优】合理浅景深允许背景及次要人物柔化；正式合影所需人物失焦则另评。

W017 【T/S｜门槛】与相邻同条件照片比较闪光漏闪、异常色偏和曝光跳变；光线确实改变时取消异常推断。

W018 【T/U｜复核】有意运动模糊、颗粒或柔焦需风格与内容支持；“动态题材”不能自动豁免失焦。

W019 【T/R｜控制】缩略图无法判断细节时读取更高质量的现有预览；解码失败报告错误，不作为内容废片。

W020 【T/S｜择优】表情动作相当时选技术更稳定的版本；细微锐度优势不抵消明显更好的情绪与时机。

## 03．逐脸可见性与视线（W021—W030）

W021 【F/V｜门槛】正式合影逐个核对需要入镜的人；任何人的脸被完全挡住时不作全员完整首选。

W022 【F｜复核】脸太小、侧转或眼镜反光导致眼睛检测不足时记录未知，不能断言闭眼。

W023 【F/V｜择优】正式合影优先视线与主拍摄方向协调；仅头部朝前不足以确认正在看镜头。

W024 【F/S｜择优】多人看向不同摄影师的正式合影，优先全员视线更一致的替代版本。

W025 【F/V｜门槛】普通正式合影中关键人物明显扭头或低头做别的事，限制自动 3 星。

W026 【F/V｜择优】互动照片允许看伴侣、长辈或道具；视线连接有助于表达关系，应获得内容优先。

W027 【F/U｜复核】婴幼儿、用户指定特殊情况采用个人容错；不因其视线未对齐否定整张关键合影。

W028 【F/V｜择优】侧脸肖像看轮廓、姿态和光线，不套用“必须正面”的正式合影标准。

W029 【F/V｜复核】墨镜、面纱和背影本身可以合理；不将不可见眼睛误算为闭眼数量。

W030 【F/S｜控制】参与者一致时才比较逐脸状态；漏检一人不能被当成那个人已经合格或离场。

## 04．笑容、眨眼与表情过渡（W031—W040）

W031 【F/S｜择优】正式合影全员状态通过后，自然大笑版本优先普通微笑版本，尊重长辈自然表情。

W032 【F/V｜门槛】多人笑容加分不能抵消另一名必要参与者明显意外闭眼或尴尬过渡表情。

W033 【F/S｜复核】区分笑到眯眼与眨眼需眼部、面颊、嘴角和邻帧证据；不足时不能肯定判废。

W034 【F/V｜门槛】正式留念中明显意外单眼闭合限制首选；明确设计的眨眼玩笑按互动类型评价。

W035 【F/V｜择优】自然微笑优于僵硬笑容；不强迫所有年龄和所有情境露齿大笑。

W036 【F/V｜复核】讲话、惊讶、唱歌或笑哭允许张嘴；只有缺乏情境的表情中断才降级。

W037 【F/V｜门槛】正式摆拍中的意外吐舌头或做鬼脸不作常规首选；有意搞怪版本另存其用途。

W038 【F/V｜择优】真实悲伤、感动或紧张按事件表达判断，不使用“笑脸少”作为纪实淘汰依据。

W039 【F/S｜择优】同一次笑声比较情绪释放自然、面部舒展的阶段；不是张嘴最大的一帧必胜。

W040 【F/U｜复核】脸部特征差异不直接等于尴尬表情；评价动作与场景，不按单一外貌模板打分。

## 05．正式合影：阵容与全员状态（W041—W050）

W041 【F/S/U｜控制】新增或减少参与者即建立新阵容，分别择优；人数最多的一张不能覆盖所有组合。

W042 【F/U｜门槛】新人和确认的必留人物状态通过，才考虑正式合影自动 3 星。

W043 【F/S｜择优】同阵容优先全员表情协调，再比较局部笑容；不以人均得分掩盖最明显的失误。

W044 【F/S｜择优】关键人物状态相近时，以其他必要参与者的整体完整性决定优先级。

W045 【F/V｜门槛】正式合影中一人正接电话、看手机或调整服装时，优先完成后的版本。

W046 【S/R｜控制】同阵容、同机位、同姿势通常留一张最佳；备用必须有表情、用途或技术上的实际价值。

W047 【F/S｜复核】一组都有人明显失误时，关键合影保留最可用代表待确认，不强行推荐 3 星。

W048 【F/V｜复核】大合影部分脸无法可靠辨认时说明检查范围，不能显示“全员睁眼已确认”。

W049 【V/S｜覆盖】正式合影后的自然笑场可作为独立互动版本保留，不与正式留念互相替代。

W050 【U/V｜覆盖】客户特别要求的家族组合按清单逐项核对；未出现的组合报告缺失，不凭相似服装认定已覆盖。

## 06．合影队形、裁切与服装（W051—W060）

W051 【V｜门槛】全身正式合影出现边缘人物意外切头或关键人物被半截切出时，优先完整替代。

W052 【V/S｜择优】比较前后排头部重叠、肩膀挡脸和站位空洞，优先人物可辨认且队形协调的版本。

W053 【V｜择优】长裙、头纱和西装线条自然舒展时优先；轻微自然褶皱不自动判废。

W054 【V/U｜复核】半身照不要求脚入镜；全身照是否切脚结合构图意图与相册用途判断。

W055 【V/S｜择优】背景杆件、招牌或亮斑明显干扰头部时，优先干扰较少的同状态版本。

W056 【V｜择优】正式队形在画面中的空间分配要稳定；建筑或环境有叙事用途时允许非居中布局。

W057 【V/S｜择优】捧花、话筒和手臂挡脸时，优先关键面部及关系更清楚的版本。

W058 【V/U｜复核】无意的衣领翻折、明显穿帮或不适当露出需要人工确认，不能仅凭模型猜测淘汰。

W059 【V｜择优】镜头边缘导致关键人物明显形变时降低常规合影优先级；有意广角趣味照另评。

W060 【V/S｜择优】横竖构图提供不同交付用途时可分别保留；只换比例且内容无新增时选择更完整版本。

## 07．新娘准备、化妆与穿衣（W061—W070）

W061 【V/F｜覆盖】化妆中闭眼属于合理动作，优先手部操作与面部细节关系清楚的帧。

W062 【V｜择优】镜中与真实人物形成清晰呼应时优先；无意义遮住主体的反射不凭技巧加分。

W063 【V/S｜覆盖】穿婚纱保留帮助者、动作与完成后的不同意义阶段，不把整个过程全部视为重复。

W064 【V｜择优】拉拉链、系绑带或整理裙摆优先关键手部可见、连接关系清楚的版本。

W065 【V/F｜覆盖】伴娘、家人整理头纱时优先关照和互动；不要求双方看镜头。

W066 【V/U｜复核】更衣中的非交付画面依据客户约定和摄影师确认处理，不自动纳入普通精选。

W067 【V/S｜择优】新娘看镜子时优先表情与姿态完成的瞬间，普通寻找工具的过渡帧降级。

W068 【V｜覆盖】婚鞋、婚纱与房间环境保留能交代准备空间的代表，杂乱本身不等于故事无价值。

W069 【F/V｜覆盖】第一次看到妆容或穿好婚纱后的家人反应，优先真实表情和人物联系。

W070 【V/S｜控制】多张相同刷子接触面部的照片只留最有表现力的代表；换动作或人物关系再评独立价值。

## 08．新郎准备与出发（W071—W080）

W071 【V｜择优】系领带、扣袖扣优先关键手部动作清楚且身体姿态自然的版本。

W072 【V/F｜覆盖】家人或伴郎帮忙整理衣服时优先互相照顾的关系，而不只选单人正面照。

W073 【V/S｜覆盖】紧张准备转为轻松笑声时，两种情绪分别有故事用途，可各留代表。

W074 【V/F｜择优】等待接亲的神情以自然专注为优先，不强制笑或看镜头。

W075 【V/U｜复核】普通调整裤腰或衣服的尴尬过渡不作肖像首选；有明确幽默故事时按纪实再评。

W076 【V｜择优】穿外套的动作优先线条舒展、脸未被衣服无意义遮住的阶段。

W077 【V｜覆盖】戒指、胸花与出发用品优先能说明准备过程的细节，不把所有物件拍摄都列为必留。

W078 【V/S｜覆盖】伴郎之间击掌、鼓励或笑场有独立互动价值，区别于列队正式照。

W079 【V｜择优】出门或上车优先方向明确、动作成立的帧；若手脚凌乱又无故事价值则降级。

W080 【V/S｜覆盖】新郎出发与家人目送可组成动作和反应，不因属于同一分钟而去掉后者。

## 09．接亲、堵门与游戏（W081—W090）

W081 【V/S｜覆盖】接亲门内门外的行动与反应分别保留有用代表，不能只围绕新郎筛选。

W082 【V｜择优】递红包、问答或找婚鞋优先动作目标可辨认的帧；没看清道具不能直接猜环节。

W083 【V/F｜择优】游戏中笑声、惊讶和参与者之间的响应优于普通等待，道具与人同时清楚时更优。

W084 【V/F/U｜复核】夸张鬼脸或吐舌头只有情境成立且交付风格允许时保留；不自动归入传统留念精选。

W085 【V｜择优】多人游戏强调关键参与者和动作链可读；背景观众不必全部看镜头。

W086 【V/S｜择优】跳跃或挑战动作比较姿态、表情和动作结果；模糊的最高点不必胜过清楚的前后阶段。

W087 【V/F｜覆盖】游戏结束后的松口气、欢呼或拥抱可独立保留，区别于挑战过程。

W088 【V/U｜复核】当事人明显不适、冲突或窘迫的画面根据摄影师与客户确认决定用途，不自动当幽默精选。

W089 【V/S｜控制】长时间相同游戏动作以关键变化择优，不按固定时间间隔机械地增加保留。

W090 【V/S｜覆盖】找到婚鞋、献花或成功进门等完成状态具有事件闭合价值，避免只留准备帧。

## 10．敬茶、长辈与家庭关系（W091—W100）

W091 【V/U｜覆盖】敬茶按实际家庭安排核对不同对象；没确认亲属关系时不自动标注父母或祖辈。

W092 【V｜择优】奉茶优先杯子、手与接收者关系清楚；合理低头不按眼部失误处罚。

W093 【V/S｜覆盖】奉茶动作与长辈接茶后的反应可分别留代表，不能只选端杯瞬间。

W094 【V｜择优】递红包、戴金饰优先接触成立、关键道具可见的帧，遮住全部动作的版本降级。

W095 【F/V｜择优】长辈轻拍、摸脸、整理衣服等关照动作以情绪与关系优先，不要求正视镜头。

W096 【F/V｜覆盖】长辈含泪、欣慰或认真叮嘱具有不同故事价值，不能以笑脸数量统一排序。

W097 【V/U｜复核】礼仪习俗以用户确认的现场流程为准，不因站姿、跪姿或顺序不同判动作错误。

W098 【V/S｜覆盖】不同家庭成员的互动分别核对，避免一位长辈照片多就挤掉其他必留人物。

W099 【V/U｜覆盖】照片中的家庭关系以确认记录组织；同龄、同桌或相似衣着不证明亲属身份。

W100 【S/F｜复核】只有一张的关键家庭互动存在轻微疑点时保留代表；明显更好同组版本存在时不增加劣质重复。

## 11．初见、对视与双人情绪（W101—W110）

W101 【V/S｜覆盖】初见可保留期待、转身认出和情绪释放的不同意义阶段，数量由实际故事增量决定。

W102 【F/V｜择优】初见优先能读到对方反应或双方连接的照片，不把看摄影师的版本固定排第一。

W103 【V/S｜择优】转身初见的时机以神情与互动成立为准，不能只按身体朝向最正选择。

W104 【F/V｜择优】相互凝视、额头贴近或轻触脸颊时，眼神与动作的情绪联系优先。

W105 【F/V｜复核】害羞、低头与笑哭可合理；不确定是情绪还是过渡动作时结合相邻帧判断。

W106 【V｜门槛】普通双人肖像中手臂或道具无意义挡住关键面部时，优先清楚替代，不凭接触距离豁免。

W107 【V/S｜覆盖】双方情绪分别清楚的两个视角可以互补；相同内容微换角度通常只留首选。

W108 【V/F｜择优】轻松互相笑、安静依靠和郑重对视分别按情绪类型评价，不规定只有大笑好看。

W109 【V/U｜复核】摆拍接吻前后与真实初见要标明用途，不能凭婚纱和两人接近就断言纪实事件。

W110 【S/U｜控制】同一情绪主题中，先保留最有内容增量的帧；不同主题不是简单重复。

## 12．单人肖像与面部角度（W111—W120）

W111 【F/V｜择优】侧脸看轮廓、颈肩和光线是否协调，不以检测到的正脸数决定肖像好坏。

W112 【V｜择优】身体姿态完成、肩颈自然、衣服线条清楚的版本优于无意耸肩或缩颈的过渡帧。

W113 【F/V｜择优】不看镜头的神情需与画面意图一致，视线有方向和情绪时可精选。

W114 【F/V｜复核】闭眼艺术肖像看面部放松、姿态完整与场景支持；偶然闭眼不能自动当氛围照。

W115 【V｜择优】全身肖像优先重心自然、裙摆或服装展开合理；不用统一体型与姿态模板评分。

W116 【V｜择优】坐姿看手脚、身体线条与环境连接，安静或不笑可成立。

W117 【V｜择优】背影肖像需身份/服装特征或环境关系可读，不能只因没有脸而降为低分。

W118 【V/S｜门槛】调整头发、搓手或刚举手的普通准备帧不作摆拍首选；明确动作主题另评。

W119 【F/V/U｜复核】面部被光影分割或部分遮住可构成创作，是否符合客户偏好需样片支持。

W120 【V/S｜控制】同姿态近似肖像选择最佳；特写、半身、全身有不同交付用途时分别择优。

## 13．双人外景、牵手与环境（W121—W130）

W121 【V｜择优】牵手照优先手的连接、身体朝向和关系自然的画面，允许背影与侧影。

W122 【V/F｜择优】两人一动一静时，看动作是否互相呼应，不强制双方同时看镜头或笑。

W123 【V｜择优】大景照片需人物与建筑、自然或空间有明确联系；脸小本身不构成废片。

W124 【V｜择优】利用光影和建筑几何时，主体位置与环境结构协调的版本优先，不强制三分法。

W125 【V/S｜择优】拥抱或依靠的摆拍比较肩颈、手臂连接与放松程度；动作无意断裂时降级。

W126 【V｜择优】婚纱、头纱与捧花在双人画面中应服务姿态和层次，无意义遮脸的替代优先降级。

W127 【V/U｜复核】两人分处前后景可有意；应确认关系可读，不能因一人柔化直接判失败。

W128 【V/S｜控制】同一外景中安静、活泼与亲密主题可分别留代表；只有位置微移不算新主题。

W129 【V｜择优】双人画面边缘保留合理动作空间，环境大景允许较多留白但需视觉平衡。

W130 【V/S｜覆盖】换地点或更换有意义环境时建立新的场景用途，不能全用人物衣服相同来去重。

## 14．动作完成、手部与网感（W131—W140）

W131 【V/S｜择优】走路连拍优先步态自然、身体线条顺、表情成立的一帧，不机械选跨步最大值。

W132 【V/S｜择优】旋转比较裙摆、发丝、身体平衡与表情；姿态有意图的阶段优先普通过渡。

W133 【V/S｜择优】跳跃以动作完整、人物关系和时机表达为准，落地前后的好表情也可胜过最高点。

W134 【V｜门槛】动作无意失衡、肢体纠缠又缺少情绪或事件价值时，不作艺术肖像首选。

W135 【V｜择优】手部关键关系应成立：牵手、拿花、扶脸、交接物品看接触和线条，不强制手指全部伸直。

W136 【V｜复核】半身构图允许手在画外；关键手部被意外切断、使动作难懂时才提出裁切疑点。

W137 【V/U｜择优】有意前景、遮挡、留白、倾斜与运动感按认可样片比较；不套“端正清晰即最好”的固定模板。

W138 【V/U｜择优】网感排序看自然度、姿态、光影与情绪是否协调；不能让流行色调抵消明确主体失误。

W139 【V/F｜复核】吐舌头或鬼脸区分有意互动与意外表情，模型不确定时按用途提供疑问代表。

W140 【V/S/U｜控制】客户认可的风格只在相同内容类型中比较；男生氛围肖像偏好不覆盖正式家族合影标准。

## 15．入场、交接与人物反应（W141—W150）

W141 【V/S｜覆盖】入场保留空间交代与关键人物出现，不能只留面部特写而看不清事件。

W142 【V/F｜择优】新人看到对方的反应比普通等待更具内容价值，眼神方向应按事件理解。

W143 【V/F｜覆盖】陪同者与新人之间的牵手、对视或扶持需要关系清楚，不要求面向摄影师。

W144 【V｜择优】交接优先接触发生、相关人物与手部关系清楚的版本，而非只看清新人的单人照。

W145 【V/S｜覆盖】交接全貌与父母反应有独立故事价值，可各自择优保留。

W146 【V/S｜择优】通道拥挤时比较关键人物、陪同者和动作的可读性，次要宾客状态不应主导评分。

W147 【V/F｜复核】仪式入场中侧身、低头与紧张表情可能合理，不套正式合影全员笑的要求。

W148 【V/U｜控制】单人入场、双人入场或其他家庭安排按实际流程评价，不推断缺失父亲就是事件不完整。

W149 【V/S｜覆盖】嘉宾起立、鼓掌或目送只有形成明确关系与反应时增加保留，避免每排都机械留一张。

W150 【V/S｜门槛】无意义遮挡切断关键交接动作且有更好替代时限制首选；唯一重要瞬间留复核。

## 16．誓言、致辞与交换戒指（W151—W160）

W151 【V/F｜择优】宣读誓言允许看稿，优先内容投入、表情自然且动作清楚的帧。

W152 【F/V｜覆盖】听誓言者的反应与发言者互补，不能因没有话筒就认为没有事件价值。

W153 【V/S｜控制】同一段誓言的口型过渡只留情绪和姿态更好的代表，不按每次张嘴都保留。

W154 【V/F｜覆盖】笑、停顿、含泪和安慰形成真实变化时分别评估，按故事增量而非时间长度留片。

W155 【V｜择优】交换戒指优先戒指与手指接触清楚、双方动作自然的阶段。

W156 【V｜门槛】只看见手却看不清戒指交换关系的细节图，不作为该事件的唯一首选。

W157 【V/S｜覆盖】交换戒指的动作全貌与关键细节可同时有用途，不能仅按画面相似淘汰一个。

W158 【V/F｜复核】交换戒指低头属于合理行为；闭眼判断不得盖过动作意义。

W159 【V/S｜择优】戴戒指遇到小意外后的笑声或安慰有独立价值，区别于普通失败过渡。

W160 【V/U｜覆盖】自定义仪式按确认流程核对关键环节，不因缺少戒指或纸质誓词就判断故事不完整。

## 17．亲吻、拥抱与情绪高潮（W161—W170）

W161 【V/F｜择优】亲吻允许双方闭眼，优先接触成立、姿态自然、人物联系可读的版本。

W162 【V/S｜复核】脸靠近不足以确认接吻；未接触但情绪完整的瞬间可按期待或双人肖像评价。

W163 【V｜择优】拥抱看身体与手臂连接、表情或动作的情感传达，不要求两张脸同时完全露出。

W164 【F/V｜覆盖】拥抱时一方的情绪反应有独立价值，不能因另一方只有背影就淘汰。

W165 【F/V｜择优】真实哭泣或笑哭以情绪和关系清晰为优先；不能按面部是否平整美化评分。

W166 【V/S｜覆盖】情绪高潮后的安慰、握手或轻拍可讲清事件结果，区别于无增量重复。

W167 【V/F｜择优】多人同时反应时优先人物之间有连接的构图，而非笑脸计数最多的一张。

W168 【V/U｜复核】脆弱、失态或不愿公开的情绪照片依据客户交付约定由摄影师确认用途。

W169 【V/T｜复核】关键情绪轻微技术瑕疵可留人工处理；严重无法辨认主体仍不能自动精选。

W170 【V/S｜控制】同一次拥抱的近似帧通常留一个情绪峰值，表情转变或关系新增才增加代表。

## 18．退场、抛花、欢呼与送别（W171—W180）

W171 【V｜择优】退场优先牵手、运动方向和喜悦关系清楚的版本，允许侧影或背影。

W172 【V/S｜覆盖】退场的场景全貌与双方表情可互补，不只保留碎纸花最密的一帧。

W173 【V｜择优】花瓣、泡泡和纸屑以服务主体为优先；遮住关键脸或动作的版本有替代时降级。

W174 【V/S｜覆盖】抛捧花保留出手与接花的不同关键阶段；只有花在空中而人物动作难懂不必首选。

W175 【V/F｜择优】接花者的反应、参与者动作和花的位置共同决定时机，跳得最高不是唯一标准。

W176 【V/S｜覆盖】捧花落地、小意外或最后庆祝在故事成立时有独立价值，不一概当动作失败。

W177 【V/F｜择优】欢呼画面优先表情、动作与人物联系协调，普通举手过渡帧不因人数多而加分。

W178 【V/T｜复核】烟花或冷焰火画面检查主体和光线是否可用，不能只因局部高光溢出判废。

W179 【V/S｜覆盖】门口告别、上车与家人目送可构成结束段落，按实际内容选择而非强制凑环节。

W180 【V/U｜控制】未发生的抛花、焰火或送别不计漏选；覆盖清单只针对确认发生的事件。

## 19．晚宴入场、敬酒与致辞（W181—W190）

W181 【V/S｜覆盖】晚宴入场应有能辨认人物与环境关系的代表，换礼服或场地可构成新阶段。

W182 【V｜择优】碰杯优先杯子、手与参与者的互动成立，面向彼此属于合理视线。

W183 【V/F｜门槛】普通敬酒留念中杯子无意义挡住关键人物整张脸时，优先未遮挡替代；真实喝酒动作另评。

W184 【V/S｜覆盖】不同桌与不同宾客各按实际关系评估，不能因背景桌花相似而合并。

W185 【V/F｜择优】喝酒与敬酒的动作瞬间按情境评价，真实表情有价值时不以张嘴或低头直接淘汰。

W186 【V/S｜控制】同桌没有内容变化的连续举杯照只选代表；独立反应特写有增量再保留。

W187 【F/V｜择优】讲话者优先自然口型、手势和情绪投入，不要求每张都微笑。

W188 【F/V｜覆盖】听众笑、流泪或互相看形成致辞反应时可独立精选，不能只留讲话者。

W189 【V/S｜覆盖】致辞的故事应看见表达与回应的联系；有价值的会意笑或安慰动作不作普通旁观重复。

W190 【V/U｜复核】饮酒后的失态、尴尬或冲突画面需摄影师确认交付用途，不能因强烈情绪自动推荐。

## 20．切蛋糕、舞蹈、音乐与晚间欢乐（W191—W200）

W191 【V｜择优】切蛋糕优先手、刀和蛋糕关系清楚，能说明两人共同动作的阶段。

W192 【V/F｜覆盖】喂蛋糕的互动可独立保留，张嘴属于动作；失去表情连贯且无故事价值的过渡降级。

W193 【V｜择优】倒香槟看瓶、杯和液体关系，关键动作被挡时优先更清楚替代。

W194 【V/S｜择优】第一支舞比较两人的身体连接、步态、表情和光线，不要求双方同时面向摄影师。

W195 【V/F/U｜覆盖】与确认的家人跳舞时优先关系与情绪；不凭人物年龄给其自动贴家庭标签。

W196 【V｜择优】群舞以主要动作、节奏和空间层次可读为先，不要求背景舞者个个正脸睁眼。

W197 【V/F｜覆盖】音乐表演或合唱中的投入表情有事件价值，不能把所有张嘴当成表情失误。

W198 【V/U｜复核】有意闪光拖影可以保留清楚的视觉中心与节奏；无法辨认主体的失误不自动变艺术照。

W199 【V/S｜控制】舞池连续近似照片按动作变化与关系新增择优，不让晚间拍得多就占满整场结果。

W200 【V/S｜覆盖】夜晚独处、收场或宾客离开可形成故事尾声，低声量的画面不因不热闹被统一挤掉。

## 21．婚戒、服装、场地与细节（W201—W210）

W201 【V/T｜择优】婚戒细节优先关键纹理、轮廓和摆放关系清楚；浅景深不要求全部背景都锐利。

W202 【V/T｜择优】请柬或誓词细节关注有意义的文字与设计，曝光失误使内容难辨时降级。

W203 【V｜择优】婚纱、鞋和配饰以主体形态及构图表达为先，不要求每件物品都必须单独交付。

W204 【V/S｜覆盖】被家人传递或佩戴的物件与静态物件照具有不同故事用途，可以分别择优。

W205 【V｜择优】花束与桌花优先形态、层次和背景整洁；有意局部特写不以不完整花束判废。

W206 【V｜覆盖】场地空镜用于交代地点、布置和空间，需选择有代表性的全貌而非每个角落留一张。

W207 【V/S｜覆盖】同一场地白天、仪式中与夜晚发生明显氛围变化时，可作为不同段落代表。

W208 【V｜择优】建筑构图看结构与主体关系，允许对称、留白和人物极小，不强制人脸加分。

W209 【V/U｜复核】有纪念意义的旧物、手写信或特殊道具需用户说明，不能因外观普通而自动淘汰。

W210 【V/S｜控制】同物件同布置的微小位移通常只留最好版本；更换用途、关系或景别再评内容增量。

## 22．弱光、逆光、天气与复杂画面（W211—W220）

W211 【T/V｜复核】逆光看主体和轮廓是否服务表达；背景天空亮不独立构成曝光废片。

W212 【V/U｜择优】剪影必须以轮廓或关系清楚为依据，不套人脸睁眼检测，风格是否适合交付由偏好确认。

W213 【T/V｜择优】舞台彩光按现场气氛与肤色可用性比较，不将正常灯光变化全部视为白平衡错误。

W214 【T/V｜复核】蜡烛、窗边和暗室允许低亮度与噪点，主体无法读懂时才限制自动精选。

W215 【V｜择优】雨伞、雨滴与风吹发丝可形成故事；需要判断关键人物与互动是否仍可读。

W216 【V/F｜复核】强风、雨雪造成的眯眼可能是自然反应；有更协调同组替代时优先替代，不一律判眨眼。

W217 【V/U｜择优】玻璃、镜面和水面反射有清楚视觉中心与关系时加分，杂乱重复影像不凭技法名称获精选。

W218 【V｜择优】前中后景多人同时发生的动作必须有可读联系；信息多但主次混乱的版本降低优先级。

W219 【V/F｜复核】头纱或前景遮挡按意图和事件价值判断，不把被检测到的每次遮挡当同一种失败。

W220 【T/V/S｜择优】复杂光线中先检查主体与故事可用性，再比较技术差异；唯一关键事件允许复核保留但不强升 3 星。

## 23．同一批人、跨组比较与重复控制（W221—W230）

W221 【S/V｜控制】分组联合时间、地点、参与者组合和动作主题；单个信号只生成候选，不自动证明同事件。

W222 【S/F｜控制】正式合影阵容识别遇到遮挡或漏检时保持未知，不能以“检测人数更少”证明有人退出。

W223 【S/U｜控制】参与者身份确认应可复用；跨组匹配不确定时不自动合并，避免不同家庭组合漏选。

W224 【S/V｜控制】同组更换近景、全景或关键反应视角时评估独立用途；不同景别并非一定重复。

W225 【S/V｜控制】跨组仍是同人物同地点同姿势且无内容新增时联合择优，减少软件误分组造成的重复。

W226 【S/R｜控制】连拍链逐渐转向或换主题时设新的比较边界，不能因为相邻帧相似就无限串成一组。

W227 【S/V｜控制】镜面中的同一个人不计为新增宾客，照片上的人脸也不自动进入现场参与者统计。

W228 【S/R｜控制】RAW/JPG 配对和导出副本先按来源关系去重，不能当作多个内容独立推荐。

W229 【S/U｜控制】用户拆组或合组保留其确认依据，重新筛选应复用，不能反复产生相同误分组。

W230 【S/R｜控制】被去掉的重复记录替代照片与原因，用户可回看恢复；相似度不直接触发源文件删除。

## 24．时机、人物关系、整场故事与风格（W231—W240）

W231 【V/S｜覆盖】每个确认发生的重要事件检查动作和有价值的回应；缺少回应时提示而非随便补一张旁观照。

W232 【V/S｜控制】期待、行动、反应和结果形成变化时按故事增量保留，不能只选择每个事件最热闹的一帧。

W233 【V/U｜覆盖】主要人物之外，确认重要的家人、朋友与帮助者应有关系画面；按实际存在与客户约定检查。

W234 【V/S｜择优】牵手、安慰、照顾和会意目光等小动作能连接人物时，比无互动的普通多人同框优先。

W235 【V/S｜覆盖】整场同时需要地点、过程、关系和结束的交代，具体段落按真实婚礼流程调整。

W236 【V/S｜控制】某环节拍摄数量多不自动增加其份额；内容增量决定保留，避免摆拍或舞池淹没其他关键段落。

W237 【V/S/U｜控制】精简相册选择能彼此衔接的全景、人物和细节；社交单张与整场交付不共用唯一数量策略。

W238 【V/U｜择优】风格参考结合用户喜欢和否定的同类型样片；只提取可验证偏好，不用点赞量证明照片质量。

W239 【R/S/U｜控制】回归验收同时检查首选命中、关键事件漏选、人物覆盖、重复保留和耗时，不只报告测试条数。

W240 【R/U｜控制】发布前核对每条启用规则的证据来源与完成状态；未接入或未验证的能力不得对用户显示为已具备。

## 典型冲突与裁决

| 情况 | 应采用的判断 |
| --- | --- |
| 正式合影有人意外闭眼，其余人大笑 | W032/W042/W043 限制首选，局部笑容不能抵消失误 |
| 正式合影自然笑眯眼，模型未找到眼睛 | W022/W033 保持未知并复核；不直接套意外闭眼门槛 |
| 亲吻闭眼或父母含泪拥抱 | W161/W164/W165 按情绪事件评价，豁免正式合影视线要求 |
| 关键瞬间有技术疑点，且没有替代 | W169/W220 留有价值代表复核，主体门槛继续限制自动 3 星 |
| 写真背影、侧脸、不笑 | W111/W113/W117/W121 按姿态与情绪判断，不强制正面大笑 |
| 好看的单张很多，但仪式反应被漏掉 | W231—W237 做整批覆盖和叙事检查，补入真实有用的代表 |
| 同场景增加一位宾客 | W041/W222 保持新阵容或未知，不能只保留人数最多的版本 |
| 目标不足，候选都是失误或低价值重复 | W001/W002 报告差额，不能强行凑满精选 |

## 后续接入与验收

本轮仅制定规则库和研究说明，未增加模型依赖、上传用户照片或修改安装包。接入方案见 [模型能力与接入说明](model-integration-guide.md)。

第一阶段验证正式合影逐脸门槛，第二阶段验证内容类型与合理豁免，第三阶段验证同阵容比较与事件覆盖，最后以用户样片补充风格。各阶段复用共享解码、预览、检测及缓存，避免重复计算。

验收样本需有完整连拍及摄影师确认结果，覆盖不同婚礼、人数、光线、肤色与遮挡程度。调参样本与验证样本分开；不因本规则库有 240 条就推断算法已经更准确。
